# ModernUI Lumen 3.13.0.10

This release includes 32 JARs: standard and MiSans editions for Fabric and NeoForge across all supported versions. CurseForge downloads are standard edition only.

- Rename the fork to ModernUI Lumen. Keep the original author’s credits and add MOPELotus as maintainer. The mod ID remains `modernui`.
- Support Fabric and NeoForge across all eight maintained branches: Minecraft 1.21–1.21.1, 1.21.6–1.21.8, 1.21.9, 1.21.10, 1.21.11, 26.1–26.1.2, 26.2, and 26.3.
- Fix text jitter in scrolling lyrics and bring the fix to every maintained branch.
- Fix tooltip layout and input issues caused by differences between Minecraft versions.
- Make changes to **Blur Effect** take effect on the current screen, while keeping **Background Fade-in Duration** working.
- Keep local music positioned relative to the listener, so moving the player does not move the sound source.
- Include configuration support in every Fabric build. **Forge Config API Port is not required**; Fabric API is still required.

For Vulkan setup and NeoForge early-window settings, see the [README](https://github.com/MOPELotus/ModernUI-MC-Lumen#readme).
