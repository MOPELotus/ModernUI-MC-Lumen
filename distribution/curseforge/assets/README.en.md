# Icon and screenshots

- [icon.png](icon.png): original 512 × 512 ML window icon, ready to use as the CurseForge project avatar.
- [icon.svg](icon.svg): editable vector source, under the repository license.
- [settings.png](settings.png): standard-edition extension settings, tooltip options, and collapsed border settings.
- [text-rendering.png](text-rendering.png): standard-edition text-rendering settings.

Both 1600 × 900 screenshots show the actual standard edition 3.13.0.10 running on Minecraft 26.3 / NeoForge. Only the desktop outside the game window was cropped. Upload them to the CurseForge Images page; the project description also links to the public repository copies.

These images demonstrate the interface, not universal device or mod compatibility. The original Modern UI interface and features are by BloCamLimb and contributors. The ML icon was created for ModernUI Lumen.
