# Minecraft 1.21.6–1.21.8 compatibility

This branch compiles against official Minecraft 1.21.8 mappings. Fabric and NeoForge have separate artifacts; the same artifact is a compatibility candidate for 1.21.6–1.21.8, while each game version needs its matching Fabric API and Forge Config API Port. Static API checks do not replace the per-version client matrix.

- The actual tooltip uniform serializer writes `mat4 modelView`, `vec4 color`, `vec3 modelOffset` plus std140 padding, `mat4 textureMatrix`, then `float lineWidth`: 164 bytes. The shader reads the 160-byte prefix; rainbow phase occupies color-matrix element `m33`. The `executeDrawRange` redirect calls the original `RenderSystem.bindDefaultUniforms(RenderPass)` and then binds the actual `ModernTooltip` slice, avoiding captured renderer locals.
- These versions use raw GLFW key callbacks `(window, key, scancode, action, modifiers)` and Screen callbacks `(key, scancode, modifiers)`. They do not use newer Minecraft input records. Core key events receive `(time, action, key, repeat, modifiers, scancode, flags)`; Caps/Num lock bits are removed while Shift/Ctrl/Alt/Super remain. Screen character input supplies UTF-16 units, which the pending text buffer concatenates without discarding surrogate pairs.
- Native text keeps moving origins outside quantized layout. A8 glyph quads include the transparent border and use a stable linear atlas sampler. Canvas text cache keys use stable local glyph positions while the draw transform retains fractional motion.
- MiSans UI weights 100–900 are nine ordered presets, not the font files’ numeric OS/2 weights. Presets 600/700 select Demibold/Semibold. Standard builds exclude installer and setup classes and use separate client configuration files.
- The official VulkanMod releases on either side of these versions target incompatible Minecraft GPU interfaces. No VulkanMod dependency is bundled or forced onto this branch; unsupported renderer backends fail before creating an OpenGL context. The shared Arc compiler and LWJGL ABI checks still apply.

`common:check` runs the actual serializer, marquee, input, font-edition, LWJGL ABI and SPIR-V array-layout checks. `-Pfont_variant=misans` selects the other compile-time edition. GPU rendering, installation, animation and all UI interactions require the physical-GPU runtime matrix; these CPU checks make no claim of GPU acceptance. Core Canvas/TextView emoji rendering and automatic TextView marquee retain their upstream implementation limits.
